# brian-perry-resume

Ongoing maintenance of a public resume and evidence portfolio using
AI-assisted workflows, source-based technology descriptions, generated
indexes, and validation.

## AI and Model

- GitHub Copilot CLI for assisted engineering and workflow coordination
- GPT-5.6 Terra for implementation and review assistance

## Tools

- Node.js and npm scripts for generation and validation
- Markdown and JSON Resume data for resume and portfolio content
- Git and GitHub for version control and publication

## Process

1. Add structured project evidence and a public project card.
2. Generate the Recent Projects index and resume Markdown drafts.
3. Enrich technology descriptions from official sources and triage the review
   queue.
4. Render and validate resume outputs before committing published changes.

This card documents public portfolio-maintenance work and excludes private
prompts, credentials, and unpublished project details.
